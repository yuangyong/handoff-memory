# ADR-001：采用本地 Markdown 作为记忆事实源

## 状态

已接受

## 日期

2026-07-12

## 背景

工具需要跨 AI 厂商、跨操作系统，并允许人类审查和修正记忆。向量数据库和客户端私有会话格式都会增加迁移与调试成本。

## 决策

使用项目内 `.ai-memory/` 目录保存 Markdown 和记忆配置。CLI 负责校验、归档和版本库状态核对，AI 负责形成语义摘要。

## 备选方案

### SQLite

查询方便，但不利于直接审查、合并和 Git diff，首版拒绝。

### 向量数据库

适合大规模历史检索，但当前核心需求是单个活动任务的准确交接，首版拒绝。

### 客户端生命周期钩子

自动化程度高，但各工具能力不一致。保留为可选适配层，不作为核心依赖。

## 后果

- 数据完全可移植，可直接由任意 AI 或文本编辑器读取。
- 历史很多时检索能力有限，未来可增加可选索引器。
- 必须通过固定结构和校验避免自由文本摘要失控。
